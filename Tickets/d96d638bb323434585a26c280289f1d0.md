## Investigation and bounded fix

- The shared importer worklist is in src/coreclr/tools/Common/TypeSystem/IL/ILImporter.cs.
- ILImporter.Verify.cs previously stopped propagation after any error and skipped errored blocks when lifetime facts were invalidated or merged.
- Consumers can filter FieldAccess/MethodAccess/TypeAccess and particular Unverifiable/UnmanagedPointer findings. These findings must not hide a later ReturnPtrToStack.
- The fix retains every diagnostic and the total error count. For exact CoreLib Span<T>/ReadOnlySpan<T> return methods, a separate count identifies these nonblocking findings and permits continued propagation/reimport only while all findings are of those kinds. Other methods and malformed-stack diagnostics keep the existing stop behavior.
- No new production class or public API; no expansion to arbitrary ref structs, generic local functions, or ref parameters.
- This preserves the Roslyn-aligned requirement established in the parent task: returned values must have a safe lifetime. The dataflow fix is specific to the existing CoreCLR-derived verifier worklist.
